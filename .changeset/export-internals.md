Export more low-level APIs from the package roots: the render presets,
`TimeEstimator`, and `deprecated` from core, and code metrics, `TxtLeaf`, curve
segments and profile helpers, `spacingSignal`, `parseShader`, transform diffing,
and `makeSignalExtensions` from 2d. `TxtLeaf` and the curve sampling helpers are
experimental.
